Privacy

Controller: Bernhard Woditschka, Vienna, Austria, talks@woditschka.com.

No data collection by this site. The pages set no cookies, run no analytics or tracking, and contain no forms. The slide software keeps two presentation settings in the browser's own storage: the scroll position of the scroll view and the speaker view's layout. Both stay on the device and are never sent anywhere.

Hosting. GitHub Pages, a service of GitHub, Inc., USA, hosts this site. When a page loads, GitHub receives the visitor's IP address and request data and logs them to operate the service and keep it secure. The legal basis is the legitimate interest in providing this site securely (Art. 6(1)(f) GDPR). GitHub transfers personal data out of the EEA under the EU–U.S. Data Privacy Framework and standard contractual clauses. GitHub determines how long it keeps these logs. Details: GitHub General Privacy Statement.

Portrait. The talk's about slide loads the author's picture from GitHub's avatar service (avatars.githubusercontent.com), which sends the visitor's IP address to GitHub as well. The request carries no referrer.

Email. A message to talks@woditschka.com is used only to answer it and deleted once the conversation ends, unless a legal duty requires keeping it. The legal basis is the legitimate interest in answering (Art. 6(1)(f) GDPR).

Rights. Under the GDPR, every visitor has the right to access, rectification, erasure, restriction of processing, and objection. Requests about the server logs go to GitHub, which holds them. Complaints go to the Austrian Data Protection Authority (dsb.gv.at) or the supervisory authority of the visitor's own country.
