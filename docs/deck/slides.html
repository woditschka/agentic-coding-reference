TL;DR

Coding agents forget and drift. Engineering discipline (TDD, DDD, ADRs, durable specs) becomes their memory and feedback.

Better prompts do not fix drift; engineering discipline does. TDD, DDD, ADRs, ubiquitous language, and durable specs become the memory and feedback the agents run on. Decisions survive across sessions; nested loops catch drift before it compounds. The pipeline is not the point; the disciplines are.
