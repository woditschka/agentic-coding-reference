Memory

The repository is the long-term memory

The context window forgets, so what matters lives in files. The conversation is where a feature starts. The human and the team share one long-term memory: the repository, specs and code alike, evolving across features. The handoff log is the team's own working memory, cleared before the next feature; the human never has to read it. The next slide opens the team box.

Agent-team

Specialists work in nested loops

The handoffs route themselves: every hop appends one record, a script decides the next step from it, the coordinator resolves only escalations and fresh intake. Four nested loops, inner to outer: TDD, review, slice, codebase. Consultation returns control to the requester, never forward.
